# detention_log.csv — Detention log (Data Spec §11.3)

One row per executed **traffic** block: how many trains it held, the **analytical
estimate** of the detention it caused, and the **actual** total. The gap between
the two is the residual the detention model learns (Blueprint §8.3):

    predicted_detention = analytical_estimate + residual_model(features)

Generated by `data/generator/build_detention_log.py`; checked by
`data/checks/validate_history.py`. **1,591 rows** (node-only disconnection blocks
raise no row — they never hold the running line).

## Schema (Data Spec §11.3)

`block_id`, `analytical_estimate_min`, `trains_affected`, `total_detention_min`,
`rerouted_count`, `cancelled_count`, `time_band`. `total_detention_min` is the
target **and the unit of the objective function**.

## The analytical estimate is a real calculation, not a random number

For each traffic block, the estimate overlaps the block window against the actual
`train_paths` on its edge and sums a genuine cost per affected train (Blueprint
§7.3): divertible trains take the ~8-minute reroute penalty; non-divertible trains
are held to the block end with a one-hop cascade; a non-divertible train on the
single-line branch may be cancelled. Each is weighted by the balanced train
priority (§7.4). If the analytical part were noise, the residual would have no
structure to learn — so it has to be arithmetic.

## The residual has the structure Blueprint §8.3 predicts

`total = analytical × (1 + residual)`, where the residual is largest exactly where
the arithmetic is known to be wrong — at **peak time bands** and on **congested
sections** — plus a little irreducible noise. Measured across the file:

| time_band | mean residual |
|---|---|
| 00-06 | 0.10 |
| 06-12 | **0.29** |
| 12-18 | 0.13 |
| 18-24 | **0.20** |

So the residual model has a real signal to recover: peak-hour holding points cost
more than the overlap arithmetic alone predicts. Most blocks sit at 00-06 (that is
where maintenance is scheduled), and their smaller residual is why the enumerator
values night windows — the model and the corridor pattern tell one story.
